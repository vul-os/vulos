# docs/assets/screenshots

Generated by `npm run screenshots` (`scripts/screenshots/capture.mjs`).

Each image is the **real** React console SPA (`web/dist` — the Vulos
Workspace: auth + user console + operator admin), driven headlessly with
every `/api/**` request answered from a bank of **fabricated** demo data —
no backend is run and no operator data is ever captured. Retina
(1440-wide @2x). The console ships a single deliberate dark instrument-panel
theme. Billing surfaces are absent by design (the OSS build resolves the
commercial seam to its NoOp implementation).

| Image | Surface |
|-------|---------|
| `login.png` | Sign in — One Vulos account for the OS, the apps and the console — email + password, an optional passkey, and social sign-in when the deployment configures it. |
| `dashboard.png` | Dashboard — The console cockpit — fleet + relay stat tiles, quick actions and the recent-activity feed. Billing surfaces stay absent under the NoOp seam. |
| `boxes.png` | Boxes — The machines running your Vulos OS: per-box version, channel, health and last-seen, as a responsive card grid. |
| `devices.png` | Devices — Every enrolled device as a manageable table — health pills, last heartbeat and a decommission action. |
| `account-status.png` | Account status — Per-account health: box reachability, relay usage/health, provisioned services and recent events. |
| `telemetry.png` | Telemetry — Per-device support diagnostics — pick a box and read its latest health signals and open alerts. |
| `enroll.png` | Enroll a box — Bind a new box to your account from the device code it shows at boot, with a plain how-it-works explainer. |
| `developer.png` | Developer — Issue scoped API keys, register webhooks and (soon) MCP servers for building on your control plane. |
| `auditlog.png` | Audit log — Who did what in your organisation — expandable, tamper-evident rows with actor / action / target filters. |
| `privacy.png` | Privacy & data — Export or erase your account data and track the compliance requests you have filed. |
| `admin-dashboard.png` | Operator — Dashboard — The operator cockpit: account / admin counts and the most recent platform audit rows. |
| `admin-accounts.png` | Operator — Accounts — Operator account search with an inline detail drawer — session state, flags and transactions. |
| `admin-audit.png` | Operator — Audit — The platform-wide, hash-chained audit trail (every tenant + system) with actor / action filters. |
| `admin-security.png` | Operator — Security — Defensive telemetry: WAF hits, bot flags, step-up challenges, ATO anomalies, honeypot + egress. |

Regenerate: `npm run screenshots` (after `npm --prefix web run build`).
