# Vulos OS Screenshots

Generated by `scripts/screenshots.mjs` (`npm run screenshots`) using Playwright
(Chromium headless).

## How they're captured (privacy-first, no faking)

The generator drives the **real shipping React shell** — the production `vite
build` bundle served by `vite preview` — and mocks the **entire backend at the
browser network layer**, exactly like the Playwright E2E suite
(`e2e/mock-backend.js`). There is **no Go server and no real `$HOME`**, so it is
impossible for real user data (files, mail, calendar) to leak into a shot: every
byte the shell renders comes from deterministic demo fixtures in the script
(user *Ada Lovelace*, home `/home/ada`, a seeded file tree, a demo agenda, the
app catalogue, the instances roster, …).

The UI is 100% real; only the data behind it is a fixture. The Terminal is the
real xterm.js widget rendering a scripted PTY stream over a mocked WebSocket — no
image is ever hand-drawn.

**Two light compositing choices** (standard screenshot hygiene, UI untouched):
apps are maximized for a full-bleed view, and the always-on menu-bar calendar
widget (which legitimately floats above windows) is hidden on maximized app
shots — it is kept on the desktop hero, where it belongs.

Captured at **1600×1000**. Dark is canonical (`<name>.png`); Light is `<name>-light.png`
where the view supports light theme well.

| `dashboard.png` | Dashboard — Web publishing (published/private apps, per-app CPU/RAM) | dark |
| `instances.png` | Dashboard — Instances (device + cloud + offline nodes, routing) | dark |

Light variants: `hero-light.png`, `files-light.png`, `settings-light.png`,
`settings-appearance-light.png`.

App Hub / Dashboard / Instances / Terminal are dark-only shots: those surfaces
are styled for a dark chrome, so a light capture would be inconsistent.

## Not captured headlessly

Streamed native apps (GIMP, LibreOffice, …) and Wine/Lutris game windows require
a `stream.Session` + GPU encoder + a live X/Wayland display, which headless
Playwright cannot provide. These are honestly omitted rather than faked.

## Regenerate

```bash
npm install
npx playwright install chromium
npm run screenshots            # builds, serves, captures → docs/screenshots/
PORT=5320 npm run screenshots  # override the preview port
```
